# Hook mapping

Visual maps of front-office hook locations in the Hummingbird theme, created by the PrestaShop Product Design team. For how hooks work, see [Hooks]({{< relref "/9/themes/concepts/hooks" >}}). For the full list of available hooks, see the [hook reference]({{< relref "/9/modules/concepts/hooks/list-of-hooks" >}}).

Each page below shows a Figma embed with hook positions and a reference table listing the page-specific hooks. Header and footer hooks are shared across all pages and are listed once on the [Home page]({{< relref "/9/themes/hummingbird/hooks/homepage" >}}).

{{% notice note %}}
These visual maps may not reflect the latest version of Hummingbird and will be updated in a future revision. They are embedded from Figma. If an embed does not load, refer to the hook table below it. The source Figma file is available in the [Hook Cartography project](https://www.figma.com/file/HKGzVBx5p2JaFrFocGe6p0/Hook-Cartography).
{{% /notice %}}
